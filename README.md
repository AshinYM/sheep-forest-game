# 양들이 잠든 숲 — 규칙 엔진과 선택적 LLM

자연어 행동을 구조화하고 Python 상태 엔진으로 게임 결과를 결정하는 규칙괴담 게임의 Advanced 버전 검토본입니다. 여러 파생 버전 중 하나만 선별했습니다.

`game.ipynb`를 위에서 아래로 읽습니다. 기본 엔진은 API 키 없이 동작하며, 노트북 안에 회귀 테스트가 있습니다. Gradio UI는 별도 패키지 설치가 필요합니다. 선택적 LLM 연동은 기본 비활성이고 실제 외부 모델을 검증하지 않았습니다. Colab 공개 터널을 만드는 마지막 셀은 명시적으로 필요할 때만 실행하세요.

추가로 `engine.py`는 노트북의 엔진·파서·회귀 검사 셀을 추출한 것으로 `python engine.py`에서 외부 API 없이 규칙 회귀 검사를 실행합니다. UI·서술 모델은 포함하지 않습니다.

다음 개선: 엔진과 UI의 명시적 모듈 분리, 행동 분류 정답 세트, 위험 행동 오분류·규칙 우회 회귀 검사.

## 공개 상태와 출처

이 저장소는 기존 학습·팀 프로젝트에서 포트폴리오 후보를 선별한 **비공개 검토본**입니다. 원본 코드의 작성 기여와 교육 제공 코드의 재배포 허용 범위는 아직 확인되지 않았습니다. 공개 전 작성자·팀의 동의와 데이터 이용 조건을 확인해야 합니다. 임의의 오픈소스 라이선스를 부여하지 않았습니다.

교안·녹취록·실제 데이터·모델 파일·DB·API 키·실행 출력은 포함하지 않습니다. 노트북 출력은 제거했습니다. 과거 결과는 이번 재실행 결과가 아닙니다.
